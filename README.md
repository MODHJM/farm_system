# 农产品销售系统

这是一个基于 vue+springBoot 的农产品销售管理系统示例学习项目。

## 项目简介

该项目用于演示系统的基本功能与模块划分（例如：农产品管理、用户管理、库存与购物车管理）。

## 环境与依赖

- Java 11
- 构建工具：Maven
- 技术栈：vue + Element-plus + spring Boot + MyBatis + Mysql


## 项目功能描述

### 管理员
- 用户管理（个人信息、密码管理）
- 商品管理（上下架、编辑）
- 公告管理（新增、编辑、删除）
- 库存管理（进货、编辑）
- 订单管理（管理发货、删除记录）
### 用户
- 订单（处理收货、退货）
- 商品展示（展示商品、添加购物车、下单支付）
